# Invitación de Boda Moderna

Proyecto web desarrollado como una invitación digital de boda, pensada para ofrecer una experiencia visual moderna y accesible desde dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Presentación de los novios
- Información del evento
- Cuenta regresiva
- Galería de imágenes
- Diseño responsive
- Código QR para compartir la invitación
- Panel o sección administrativa

## Demo

[Ver demo en Netlify](https://bodainvitacionlydigitalsystems.netlify.app/)

## Objetivo del proyecto

Este proyecto fue desarrollado para practicar la creación de experiencias web visuales, diseño responsive, organización de contenido e interacción con JavaScript.
